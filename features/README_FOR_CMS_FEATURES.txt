CMS IMAGE / DATA NOTES

Hotel Features and Promotions are now inside hotel-features.html.

Data files:
- assets/data/hotel-features.js

Main arrays:
- window.IPTV_HOTEL_FEATURE_CATEGORIES
- window.IPTV_HOTEL_FEATURE_ITEMS
- window.IPTV_HOTEL_PROMOTIONS

To add/edit facilities, spa, restaurant, and housekeeping items, edit IPTV_HOTEL_FEATURE_ITEMS.
To add/edit promotions, edit IPTV_HOTEL_PROMOTIONS.

Promotions are displayed inside the Hotel Features page when the Promotions category is selected.
Welcome page promotion cards link into:
- hotel-features.html?category=promotions&promo=breakfast
- hotel-features.html?category=promotions&promo=spa
- hotel-features.html?category=promotions&promo=stay-more

Keep images around 16:9 or portrait card-friendly. Replace image paths only; layout will remain the same.
