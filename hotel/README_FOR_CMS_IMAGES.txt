CMS image replacement notes

The Welcome page room gallery uses these three image paths:
- assets/hotel/room-bedroom.jpg
- assets/hotel/room-wardrobe.jpg
- assets/hotel/room-bathroom.jpg

The promotion cards use these image paths:
- assets/promotions/breakfast-buffet.jpg
- assets/promotions/spa-retreat.jpg

To let a CMS/admin change the pictures later, keep the same file names and replace the image files in these paths, or update the src paths in welcome.html. Recommended display size for the hero gallery is 740 x 290, with enough safe area on the left because the dark text gradient overlays that side.
